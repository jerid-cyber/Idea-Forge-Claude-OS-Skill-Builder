# Mode 3: Gap Check

Goal: close only the gaps that would change what gets built, using as little of the person's attention as possible.

## Ranking gaps

Score each `GAP:` item in the blueprint by impact:

1. **Blocking:** without it, the skill would do the wrong thing (unclear purpose, unknown output format, contradictory rules, unknown audience).
2. **Shaping:** it changes the architecture or a major section (one skill vs. several, which platform, how much autonomy).
3. **Polishing:** nice to know; a sensible default works fine (exact tone nuances, minor naming).

Ask blocking gaps first. Ask shaping gaps only if there's no strong default. Never ask polishing gaps; use defaults and list them in Temper as things the person can tweak.

## How to ask

- **At most 3 questions per round.** If a tappable-options tool is available (for example on mobile), use it for questions with clear options.
- **Every question comes with a default.** "If you're not sure, I'll go with X." This lets the person answer "defaults" and move on.
- **Ask in their language,** not skill jargon. "When should this kick in?" beats "What are the trigger conditions?"
- **Use examples to ask about judgment.** "If a client says X, would you do A or B?" gets better answers than "How do you handle objections?"
- **Resolve contradictions explicitly.** "Your notes say always A, but your example does B. Which wins, or does it depend on something?"

## When to stop

Stop when the remaining gaps are all polishing-level, or after the person says to use defaults. Two rounds is typical; three is the soft ceiling. If blocking gaps remain after three rounds, say which ones and propose the safest default rather than continuing to ask.

## Update the blueprint

Write the answers into the blueprint, remove the `GAP:` markers, and mark defaults you chose as `(default)` so Evolve can revisit them later.
