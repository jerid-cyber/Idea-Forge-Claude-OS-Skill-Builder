# Local Pattern Library

Your own lessons from your own forges. Read alongside `community-patterns.md` during Architect and Temper. When they conflict, your local lesson wins.

Add a lesson only when it applies beyond one skill. Use the same format as the community library so lessons can be shared later:
`- **<pattern>** — <why> (source: <skill name, date>[, evidence: <what happened>])`

## Lessons
- **Self-corrections in voice dumps: keep the last version stated.** — Speakers revise mid-thought ("200, actually no, 150"); the final figure is the decision. (source: new-agent-30-day-coach test forge, 2026-10-02, evidence: dump contained a corrected quota)
