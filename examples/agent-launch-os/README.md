# Agent Launch OS

Get every new agent to their first appointment within 30 days.

## What's inside
- **agent-launch-command-center**: decides what runs next
- **agent-launch-brain-setup**: sets up the system's memory
- **agent-launch-heartbeat**: runs it on a daily schedule
- **sphere-builder**: Sphere builder
- **daily-call-coach**: Daily call coach
- **appointment-tracker**: Appointment tracker
- **open-house-planner**: Open house planner

## Get started
Install the plugin, then say: "Set up Agent Launch OS." After setup, say "Run my Agent Launch OS daily cycle", or ask for the heartbeat to put it on a schedule.
